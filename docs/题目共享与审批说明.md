# 题目共享与审批

本页为2026年10月29日最新确认规则。用户将之前“只限指定问卷”调整为可选择面向用户或面向用户的部分问卷，并加入用户修改分支。旧单问卷记录及历史验证保留，不自动扩大权限。

## 两种授权范围

| 范围 | 可使用的问卷 | 是否允许修改分支 |
| --- | --- | --- |
| 面向用户 | 该用户当前及未来创建的全部问卷 | 允许基于获准原版本创建自己的修改分支 |
| 该用户的部分问卷 | 明确选择的1～50份本人草稿 | 只允许复用获准原版，不开放修改分支 |

两种范围都固定题目版本，不自动授权原作者未来新增版本。目标仍是指定用户，不能用于其他用户的问卷。未审批、拒绝和撤销不赋予新的使用权。用户级与部分问卷授权分别存在；收窄为部分问卷时，须先撤销原来仍有效的用户级授权。

## 申请、主动授权与撤销

需求者从“题目与题库 → 共享申请与审批”填写出题者提供的题目编号、版本号、范围和说明。部分问卷范围可多选本人草稿；用户范围无需先建草稿。出题者审批时能明确看到是全部问卷还是指定问卷，可批准或拒绝。

出题者也能在原题版本页填写需求者用户名，并选择用户范围，或提供该用户多份草稿编号主动开放使用权。后端先检查所有部分问卷编号、归属及草稿状态，再写入各自记录。每份问卷单独记录审批及撤销结果，不是整批事务。

重复提交复用同一有效记录，MongoDB部分唯一索引防重复；拒绝或撤销后重新申请保留旧记录并创建新记录。旧页面不能覆盖已处理状态。旧shared_with数组仅保留历史，不作为授权依据。

撤销不删除已有题目副本、问卷、回答和统计，已有问卷仍可继续填写。撤销用户级授权后，接收者可查看自己已保存的分支历史，但不能继续修改/恢复分支或新增导入；如仍有部分问卷授权，仅可按其范围复用原版。重新取得用户级授权后可继续使用分支。

## 用户修改分支的保存方式

面向用户授权的接收者，在原题版本页点击“基于v1修改为我的分支”，复用题型编辑器修改并保存。首个修改版本显示为“用户名分支 v2”，记录源作者、源v1、修改人和说明；若从v2修改，则分支首版为用户名v3。后台以分支及版本编号唯一识别，显示名不作为权限依据。

后续可在自己的分支中继续新增版本或恢复为新版本。原作者的v1/v2及其他人的版本不覆盖。分支不能转授给第三人，不能继续复制或另存来移除来源授权。此限制控制应用操作路径，不能阻止人手工抄写已经看到的文字。

保存新分支不会自动改变问卷。可把分支加入自己的草稿，或在分支详情中明确选择替换某份草稿里原题/当前分支的引用。替换保留本地题号，并清空该问卷全部跳转，请重新配置；过期表单冲突，已发布问卷不能替换。替换前已生成的填写进度继续依照原版本摘要保护处理。

## 回答数据和引用问卷访问

同一道题在不同问卷所有者之间的回答数据相互封闭，原作者也不能查看其他所有者的答案或统计。原版、分支和各版本分别汇总，不因为来源相同就混算。

原题作者可以核对全部引用记录，包括基于该题版本的用户修改分支引用。仅正在开放的引用问卷提供只读全文入口；草稿404，截止和关闭410，非作者或无引用404。查看不写responses、不开放编辑、答案或统计；普通填写链接仍先显示介绍并逐题填写，没有新增全站问卷广场。

## 兼容性与验证边界

旧授权记录、问卷、回答及第一阶段source缺省数据保留。只升级精确匹配的已知旧授权校验器，未知结构停止。用户级授权通过survey_id=null表达，原ObjectId记录仍只授权原问卷。

权限检查和写入未使用跨集合事务，撤销前已准入的在途请求可能完成；关闭无法撤回已经阅读的内容。自动验证见[第二阶段测试用例](第二阶段测试用例.md)P2-52～P2-63及[本轮结果](验收证据/第二阶段/范围与分支-验证.json)。第二阶段手机人工验收仍未执行。

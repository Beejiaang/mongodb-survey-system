# 统计结果

在自己问卷的详情页点击“查看统计”，可看汇总与各题数据，并进入单题页面。单选、多选和数字题提供“展示方式”菜单，可在图表与数据表格之间切换；文本题不提供图表或切换菜单；原填空答案列表及平均值继续保留。

## 图表切换

| 题型 | 可选展示 |
| --- | --- |
| 单选、多选 | 条形图、柱状图、饼图、环形图、数据表格 |
| 数字填空 | 分布柱状图、分布条形图、频数折线图、数据表格 |
| 文本填空 | 不提供图表；保留回答数量，单题页按列表查看原文 |

选择只影响当前题，切换立即生效，不重新提交或改写问卷数据。本浏览器按问卷与题目记住选择，进入单题页和刷新时可延续；localStorage不可用时仍可切换，但不持久化。这里仅保存展示方式，不保存答案。

多选条形/柱状图显示每个选项被选择的回答份数。多选饼图/环形图展示各项占“全部选中次数”的构成比例，例如5份回答中各项都被选3次，总选中9次，则各项为33.3%；原数据表格的人数占比仍为3/5=60.0%。两种口径在界面分别说明，不将总选中次数当作回答人数。

单选圆形图的分母是该题有效回答份数。文本题保留有效回答、选答留空和被跳过的计数，不生成图表数据。

数字图表针对所有正式数字回答，在MongoDB使用bucketAuto生成至多10个按数值排序的区间，不受答案列表分页影响。区间可能不等宽，柱宽不表示数值跨度，纵轴显示频数；横轴序号与完整图例对应。折线连接区间频数，不表示时间趋势。区间左闭右开，最后一段包含右端点；单个数值直接用该值标记。64位整数边界以字符串传给浏览器，避免JavaScript转换丢精度。

零数据时显示“暂无可绘制的数据”，不画有面积的圆形图；只有一个有效选项时绘制完整圆。长标签在图内缩略，图例保留全文；手机上的宽图在自身区域内滚动。

图表由static/result-charts.js本地SVG绘制，无外部库或CDN请求。JavaScript不可用时默认数据表格仍在；绘图异常时也回退表格。下拉菜单、SVG可访问名称、完整文字图例和数据表格一起保留可读数据。

## 统计口径

只读取本问卷 `responses.state = submitted` 的正式回答。draft 进度不计入；份数、选项计数、占比和数字平均值按每次正式提交计算。单选题另显示“总回答人数”：回答本题的账号去重人数，重复填写只计一人，留空和跳过不计入。匿名问卷同样可以通过内部标识去重，不展示身份；人数表示账号数，不能识别一人持有多个账号的情况。

| 指标 | 计算方式 |
| --- | --- |
| 正式提交 | 本问卷已提交记录总数 |
| 本题有效回答 | 题目在本次 path 中且答案不为 null 的份数 |
| 单选总回答人数 | 正式提交、实际经过且有效回答本题的不同账号数 |
| 选答留空 | 题目在 path 中，但确认留空的份数 |
| 被跳过 | 题目未出现在 path 中的份数 |
| 单选选项份数 | 有效回答中选择该选项的份数 |
| 多选选项份数 | 有效回答中包含该选项的份数，一份可计入多个选项 |
| 选项占比 | 选择该项份数 ÷ 本题有效回答份数，显示一位小数 |
| 数字平均值 | 本题有效数字之和 ÷ 有效数字回答份数，显示两位小数 |

例如四份提交中，某道多选被跳过两次，剩下两份分别选择 A+B 和 B，则有效回答为2、跳过为2；A 为1份/50.0%，B 为2份/100.0%，各项占比之和可以超过100%。

数字0是有效回答，留空及跳过不作为0参与计算。无有效数字时显示“—”。平均值先用精确分数累加，避免64位整数或极大有限浮点数求和溢出，再转十进制按默认四舍六入五成双规则显示两位小数。原始数字答案保留原存储值，页面不先将整数转浮点。

当前发布后题目及选项锁定，统计依赖稳定题目/选项编号。外部直接修改已发布题目不是支持的数据迁移方式。

## 页面与权限

| 地址 | 方法 | 内容 |
| --- | --- | --- |
| /surveys/问卷编号/results | GET | 正式提交总数、题目数，以及各题汇总 |
| /surveys/问卷编号/results/questions/题目编号 | GET | 单题计数或数字平均值，以及填空答案列表 |
| 同上，附 ?page=2 | GET | 填空答案下一页，每页最多20条 |

页面要求登录，服务端先检查问卷 owner_id。只有创建者能查看自己的结果，填写过问卷也不会获得结果权限。其他账号、未知问卷和未知题目返回404；未登录跳转登录。草稿显示空统计，已截止或关闭的问卷仍可查看已有结果。

填空答案按 submitted_at、_id 稳定倒序排列，显示序号、答案和北京时间；只读取实际路径中的非空答案。非法页码返回400，越界页返回404。手机上的宽答案表格可以在表格区域内横向滚动。

匿名与实名结果均不展示填写者身份；查询投影和页面不传出 user_id、respondent_key、填写记录编号或用户名。文本与题目/选项自动HTML转义。

## 实现与兼容性

`survey_results.py` 负责汇总与答案分页，`result_views.py` 负责权限和页面。展示模板独立；选择题图表复用同一选项计数，数字分布以独立MongoDB聚合补充。

汇总仅投影 answers、path，用一次游标扫描计算总数及各题数据，内存不随回答份数增加。单选人数通过MongoDB按题目及respondent_key分组去重，只向应用返回每题计数；内部身份标识不传给结果页面。填空内容使用 MongoDB 聚合排序与分页，不把全部文本加载到页面。复用已有 `survey_submissions` 索引，不增加集合、字段或迁移要求。

图表数据与答案列表可能分次读取；统计页面为只读，每次页面请求按当前已提交数据计算；新提交后刷新可见更新，不建立统计缓存。不同页面是独立读取，持续有新提交时数字及分页位置可能随刷新变化，不提供冻结快照。

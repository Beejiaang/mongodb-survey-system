# 发布 截止 关闭与分享

创建者在问卷详情的“发布与分享”区域管理问卷。先保存截止时间（可留空），再点击“发布问卷”；发布后出现固定分享地址和复制按钮。截止时间、发布及关闭均由后端检查登录身份、问卷归属和 CSRF。

## 生命周期

| 当前状态 | 可进行的操作 | 分享入口 |
| --- | --- | --- |
| draft 草稿 | 添加题目、设置截止时间、发布 | 404，不向接收者展示 |
| published 已发布，未截止 | 设置截止时间、关闭 | 登录后200，展示问卷内容 |
| published 已达到截止时间 | 延长或取消截止时间、关闭 | 登录后410，提示已截止，不展示题目 |
| closed 已关闭 | 查看保留的数据及原链接 | 登录后410，提示已关闭，不展示题目 |

发布至少需要一道有效题目，并重新检查整份题目配置。发布时写入 UTC `published_at`、`updated_at`；发布后题目锁定。重复发布返回409，首次发布时间不会被覆盖。关闭仅对已发布问卷有效，保留题目和日期；本阶段不支持将 closed 重新发布。

“已截止”是由 published状态和deadline实时计算的展示状态，数据库仍保留published，不新增第四种存储状态，也不需要定时任务。每次分享请求都会检查截止时间。在截止瞬间（当前时间大于或等于deadline）即拒绝开放。延长或取消已截止问卷的时间限制会重新开放，页面已提示这个行为。

## 时间规则

网页使用datetime-local控件，明确按北京时间UTC+8输入，精确到分钟。后端转换为UTC后保存BSON Date；展示时转回北京时间。留空表示无截止时间，设置的时间必须严格晚于当前时间。错误日期、过去时间、恰等于当前时间和超出时区转换范围的日期返回400，不修改原文档。

创建者可以在草稿阶段先设截止时间。若到发布时已经过期，需要先修改截止时间才能发布。对已有published问卷修改deadline时，不改变published_at。

## 请求接口

| 地址 | 方法 | 结果 |
| --- | --- | --- |
| /surveys/编号/deadline | POST | 表单字段deadline，保存成功303返回详情 |
| /surveys/编号/publish | POST | 发布成功303返回详情 |
| /surveys/编号/close | POST | 关闭成功303返回详情 |
| /survey/编号 | GET | 接收者的分享入口 |

三种管理操作拒绝GET（405），其他账号和不存在的问卷返回404，状态冲突返回409。错误配置返回400，并在详情显示原因。更新使用数据库原子条件：发布时匹配刚校验的题目数组、截止时间、草稿状态及归属；并发内容变化时要求重新检查后重试。并发发布只有一个请求成功，关闭与截止时间修改也在数据库更新条件中校验归属及状态。

## 分享与登录

分享地址固定为 `/survey/问卷编号`，与仅创建者可见的 `/surveys/问卷编号` 管理页分开。发布后可复制完整地址；浏览器剪贴板不可用时自动选中地址，提示手动复制。复制链接不会自动发送给任何人。

接收者必须先登录，包括匿名问卷。未登录访问会带next参数跳转登录；注册页面和登录表单保留目标，完成登录后回到原问卷。后端仅允许 `/survey/24位十六进制编号` 作为登录回跳目标，拒绝外部URL及其他路径，防止开放重定向。

分享页现提供“开始或继续填写”，进入逐题表单、确认页和提交回执。答案保存落实匿名及重复填写设置；提交时在 MongoDB 单文档原子操作中再次检查状态和截止时间。关闭前已成功准入的提交可完成保存，关闭后新准入被拒绝；详细并发边界见 [填写与答案保存说明](填写与答案保存说明.md)。

本机的127.0.0.1/localhost链接只在当前电脑上可用。其他设备需通过局域网IP或已部署的主机地址访问；详情页按当前请求Host生成分享URL，创建者需从可访问的地址打开详情再复制。真实两设备验收步骤见[测试用例N01](测试用例.md)，目前待执行；Flask客户端模拟IP/端口的检查不验证监听、防火墙或路由器连通性。

本步沿用原有12字段和索引，没有数据库迁移。测试和浏览器操作全部使用独立临时库，保留业务数据。

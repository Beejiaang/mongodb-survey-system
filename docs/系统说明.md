## 使用角色与功能

所有账号具备相同能力：可以创建自己的问卷，也可以填写其他人发布的问卷。创建者身份由具体问卷的owner_id决定，没有单独的管理员角色。

| 功能 | 创建者 | 登录后的填写者 |
| --- | --- | --- |
| 注册、登录、退出 | 可以 | 可以 |
| 查看和创建自己的问卷 | 可以 | 可以创建自己的问卷 |
| 添加题目、配置限制和跳转 | 仅自己的草稿 | 无权管理他人的问卷 |
| 发布、设置截止时间、关闭 | 仅自己的问卷 | 无权操作他人的问卷 |
| 通过固定链接填写 | 问卷开放时也可以填写 | 问卷开放时可以填写 |
| 查看整卷及单题统计 | 仅自己的问卷 | 填写过不代表能查看结果 |

匿名问卷仍要求登录；匿名是结果对创建者隐藏身份，服务端保留按问卷隔离的内部标识以恢复进度、去重和防重复。

## 创建与管理流程

1. 注册后登录，从导航进入“我的问卷”，列表按创建时间倒序显示当前账号创建的问卷。
2. 点击“创建问卷”，填写标题、说明，以及匿名和允许重复填写设置，保存为草稿。
3. 逐题添加单选、多选、文本填空或数字填空；设置必答、选择数量、文本长度、数字范围和整数要求。
4. 仅回答数字的题目选择数字填空。题目旁可一键添加“请使用阿拉伯数字回答”；从文本题点击时同时转换为数字题，保留标题和必答，最后点击保存。
5. 在草稿题目下配置跳转并试算；多选明确区分“至少包含指定项”和“恰好选择指定项”，数组靠前的命中规则优先。
6. 在问卷详情设置北京时间截止时间，至少有一道有效题目后发布。发布后锁定题目，显示固定的 `/survey/<survey_id>` 链接及复制按钮。
7. 可修改或取消截止时间，也可手动关闭问卷。自动截止通过时间实时判断；延长时间可恢复开放。手动关闭后当前不支持重新发布。
8. 点击“查看统计”查看整卷汇总；点击题目下“查看单题统计”或“查看填写内容”进入单题页面。

草稿只对创建者可见，已关闭或截止的问卷停止接受新的提交；已有回答和创建者的结果查询保留。

## 填写流程

接收者打开分享链接，未登录时先登录，成功后返回原问卷。点击“开始填写”或“继续填写”进入当前题；每次点击“保存并继续”先校验答案，再保存到MongoDB并按规则跳题。没有点击保存的当前输入尚未持久化。

刷新或重新登录可继续已保存进度。“上一题”沿实际路径返回；修改前题并保存后会清除其后所有旧答案，需要重新填写后续题。最后进入确认页，只展示最终实际经过的题目，确认提交后显示本人回执。已提交的回答不能修改。

创建题型入口为单选、多选、填空，填空内部选择文字/数字；选择题以A、B起始逐行输入并用加号添加。分享入口只保留退出及开始/继续填写，不展示整卷题目。填写页不常驻显示数字格式和上下限说明，无效输入会提示原因并阻止保存前进。数字题的浏览器格式检查与后端强制校验共同拒绝文字、全角数字和单位；数字格式允许ASCII 0–9、正负号、小数和科学计数法，还必须满足该题的整数及范围限制。

## 结果展示

整卷页显示正式提交份数、题目数和各题汇总；单题页只展示指定题目，并提供填空答案分页，每页20条。草稿填写进度不计入统计。

| 题型 | 数据 | 可切换展示 |
| --- | --- | --- |
| 单选 | 总回答人数（账号去重）、有效份数、留空、跳过、各项份数及占比 | 条形、柱状、饼、环形、表格 |
| 多选 | 有效份数、留空、跳过、各项份数及占比 | 条形、柱状、饼、环形、表格 |
| 文本填空 | 回答状态计数，单题页查看原文 | 不提供图表 |
| 数字填空 | 有效计数、平均值、全量数字分布和原始数字 | 分布条形、表格 |

允许重复填写时，份数和平均值按每次正式提交计算；单选人数同账号只计一人。多选表格占比以有效回答份数为分母，圆形图以总选中次数为分母。数字0计入平均值，空白和跳过不计入，无有效数字显示“—”。完整口径见 [统计结果说明](统计结果说明.md)。

## 系统结构

浏览器通过普通HTML表单访问Flask；路由负责登录、权限、参数和页面，业务模块负责校验、路径、保存与统计，PyMongo保留原三个核心集合并新增三个题库集合。模板由Jinja渲染，少量JavaScript用于复制链接和SVG图表，没有现成问卷系统框架。

| 层次 | 主要文件 | 作用 |
| --- | --- | --- |
| 应用与身份 | app.py、auth.py、users.py | 工厂配置、路由注册、会话、CSRF、用户名和密码哈希 |
| 管理页面与业务 | survey_views.py、surveys.py | 草稿、追加题目、规则保存、发布、截止、关闭与归属 |
| 题目与跳转 | questions.py、numeric_input.py、jumps.py | 配置、答案、数字格式、首条命中及实际路径 |
| 填写 | response_views.py、responses.py | 恢复进度、逐题保存、版本比较、提交准入与回执 |
| 统计 | result_views.py、survey_results.py | 创建者权限、整卷与单题统计、平均值和答案分页 |
| 存储约束 | database.py、survey_schema.py、response_schema.py | 连接、初始化、校验器、索引与已知旧结构兼容 |
| 界面 | templates/、static/ | 页面、样式、复制链接和本地图表 |

## 运行与配置

已在本机Python 3.12.10与MongoDB 8.0.22环境验证，Python依赖由requirements.txt固定。安装、init-db与启动命令见 [README](../README.md)。MongoDB需另行安装并运行，本机辅助启动脚本不随项目分发。

| 配置 | 默认或来源 | 用途 |
| --- | --- | --- |
| MONGODB_URI | mongodb://127.0.0.1:27017 | 数据库连接 |
| MONGODB_DB_NAME | survey_system | 业务数据库名 |
| FLASK_SECRET_KEY | 缺省在instance/session-key生成 | 签名会话 |
| RESPONSE_IDENTITY_KEY | 缺省在instance/response-identity-key生成 | 匿名内部标识和回答归属 |
| MONGODB_TEST_URI | 测试默认连接本机27017 | 独立测试数据库连接 |

本项目直接读取环境变量，不会自动读取.env文件。instance目录被Git忽略，不随代码提交。密钥需稳定保存；多实例需共享相同密钥，已有匿名标识不能在不迁移数据的情况下直接换密钥。

当前本机地址仅本机可访问。代码不依赖公网服务或图表CDN。当前没有已保存题目的编辑删除、跨题组合条件、回答导出和公网部署；这些未作为第一阶段基本功能的完成条件。并发测试覆盖正确性，不是高并发吞吐或长时间压力测试，性能边界见 [关键逻辑说明](关键逻辑说明.md)。

## 第二阶段题目与题库

登录后主导航增加“题目与题库”。可独立创建题目，也可在问卷详情保存某题为常用题；从已有题目或题库选题时选择确切版本。版本详情展示内容差异、修改说明、历史和派生/恢复关系，恢复旧内容会生成新版本。草稿上移、下移和删除会清空全卷跳转。

需求者按指定目标问卷申请，经作者审批后使用；作者也可主动按用户名、目标问卷及版本授权或撤销。共享不能用于其他问卷，不能派生或另存为自己的常用题，不能修改原作者历史。共享不开放回答数据。题库支持创建、名称说明修改、条目增删、指定版本更新和删除容器。跨问卷统计按版本只汇总当前用户自建问卷；原问卷统计保留。完整规则见[第二阶段报告](第二阶段项目完成报告.md)。

共享具体流程与状态见[题目共享与审批说明](题目共享与审批说明.md)。

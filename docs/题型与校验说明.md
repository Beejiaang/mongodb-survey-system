# 题型与校验说明

`questions.py` 提供题目配置和单题答案校验，支持单选、多选、文本填空和数字填空。创建问卷及添加题目页面已经复用本模块，并接入 surveys 数据库级结构校验。跳转执行、整卷提交和统计尚未实现。

## 与作业要求的对应

课程原始文件《大作业一.docx》的“初始用户需求／三、问卷中的题目”要求单选、多选、填空三种题型，填空分文本和数字。选择数量、文本长度、数字范围及整数要求均落实为可配置规则，而非针对具体题目写死。

| 题型 | type | 补充字段 | validation 字段 |
| --- | --- | --- | --- |
| 单选 | single_choice | options | 空对象 |
| 多选 | multiple_choice | options | min_choices、max_choices |
| 文本填空 | fill_blank | input_type = text | min_length、max_length |
| 数字填空 | fill_blank | input_type = number | min_value、max_value、integer_only |

所有题目包含 `id`、`type`、`title`、`required`、`validation`、`jump_rules`。题目嵌入问卷的 `questions` 数组，数组顺序决定展示顺序；题目编号在同一问卷中唯一，调整顺序和修改标题时保留原编号。选择题选项为 `{id, text}`，答案引用选项编号，不引用选项文字或位置。

`build_question()` 为新题生成 UUID 字符串编号，也可通过 `question_id` 保留已有编号；选择题的选项编号由调用方提供并在校验时检查。`required` 默认为 false，上下限默认 null，`integer_only` 默认 false。调用方可只传部分规则，由构建函数补齐默认值；直接校验已有文档时要求字段完整。

## 配置检查

- 标题、题目编号、选项编号和选项内容必须为非空字符串，去除首尾空白；未知字段或与题型不符的字段报错。
- 选择题至少两个选项，同一题内选项编号不得重复。这是本项目采用的配置规则，课程没有规定选项最少数量。
- 数量和长度限制必须为非负整数或 null；数字上下限必须为有限数值或 null，布尔值不能充当数字。
- 上下限包含边界；最小值不得大于最大值。多选上下限均不得超过选项总数。
- 必答多选题的最多选择数、必答文本题的最长长度不能为零；整数题上下限之间必须有可取整数。
- 草稿可以暂时没有题目。发布时的整卷完整性检查随发布功能实现。
- `jump_rules` 当前必须为空数组，非空明确报错。课程要求的单选、多选、数字跳转将在后续步骤实现，不能把已有配置静默忽略。

## 答案检查与返回值

`validate_answer(question, answer)` 先验证配置，再验证答案；失败抛出带中文原因的 `ValueError`，成功返回独立值，不修改调用方输入。

| 题型 | 接受的已填写答案 | 检查内容 |
| --- | --- | --- |
| 单选 | 一个选项编号字符串 | 编号必须存在 |
| 多选 | 选项编号数组 | 编号有效、不重复，数量符合上下限 |
| 文本填空 | 字符串 | 按 Unicode 码点计算长度，符合上下限 |
| 数字填空 | 整数或有限浮点数 | 符合范围和 integer_only 要求 |

未提供答案用 `None` 表示。多选空数组、文本空字符串或纯空白也视为未填写；必答题拒绝未填写，非必答题返回 `None`。非必答题一旦填写，仍须满足最小限制。数字零是有效答案，不能当成未填写。

文本原样保留，非空文本的首尾空格也计入长度。中文、字母、标点均计数；组合字符和复杂 emoji 可能包含多个码点。后续浏览器应按同一规则计数，不能直接依赖 JavaScript UTF-16 的字符串 length，最终以后端检查为准。

数字字符串（如 `"18"`）在此数据层被拒绝，后续网页输入应先明确转换为数字。`18.0` 数学上为整数，可用于整数题。整数采用 BSON 支持的有符号 64 位范围，浮点数拒绝 NaN 和正负无穷；从 MongoDB 读回的 `Int64` 同样可校验。当前不提供任意精度小数规则。

## 调用示例

```python
from questions import build_question, validate_answer, validate_questions

question = build_question(
    "multiple_choice",
    "你喜欢哪些水果？",
    required=True,
    options=[
        {"id": "apple", "text": "苹果"},
        {"id": "banana", "text": "香蕉"},
        {"id": "grape", "text": "葡萄"},
    ],
    validation={"min_choices": 2, "max_choices": 2},
)
questions = validate_questions([question])
answer = validate_answer(question, ["apple", "banana"])
```

这里“必须选两个”通过上下限都为 2 表示。函数不会自行保存问卷或答案；当前问卷服务已在追加题目前调用校验，后续提交服务还需在答案写入前调用校验。

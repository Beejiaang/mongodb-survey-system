# 第一次大作业开发计划

本项目按步骤完成，每一步先理解设计，再实现功能并验证结果。当前已完成运行环境准备、Flask 首页、模板渲染和 Git 基础文件准备。

## 开发顺序

1. 设计用户集合，明确用户名唯一性、密码哈希和注册时间，接入 MongoDB。
2. 实现注册、登录、退出，以及登录状态和权限检查。
3. 设计问卷和题目结构，实现问卷创建、题目配置和“我的问卷”。
4. 实现发布、截止时间、关闭状态和分享链接。
5. 实现各题型校验、可配置跳转和填写流程。
6. 保存回答，落实匿名填写和重复填写设置。
7. 实现问卷与单题统计。
8. 完成测试、系统与数据库文档、API 说明和项目报告。

## 需要在实现前明确的规则

- 题目要求填写者先登录，同时允许匿名填写；需要明确匿名时保存哪些身份数据，以及问卷创建者能看到哪些信息。
- 多选题可能同时匹配多个跳转规则，需要确定规则优先级。
- 需要决定如何处理跳转循环，以及被跳过题目的必填校验。
- 需要明确重复填写是否允许，并由后端执行限制。
- 问卷已有回答后，修改题目和选项可能影响旧答案与统计，需要确定修改策略。

这些规则尚未实现，应在对应步骤确定并记录理由。

## 验证与文档

作业要求覆盖创建问卷、添加题目、跳转逻辑、校验、提交问卷和统计测试。每项记录测试步骤、输入、预期输出、实际输出和结果。

数据库说明应解释集合划分、嵌入或引用的选择、索引以及设计为何适合 MongoDB。第二阶段继续沿用第一阶段代码，并记录需求变更、结构调整和兼容性验证。
